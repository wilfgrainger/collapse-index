# Contributing

Contributions are welcome, especially source validation, statistical review, accessibility testing and resilient public-data collectors.

Before opening a pull request:

1. explain the evidence or user problem being addressed;
2. keep methodology changes separate from presentation changes;
3. add or update tests;
4. preserve source dates, units and status fields;
5. run `npm run check`;
6. update `docs/DECISIONS.md` for changes to weights, thresholds, confidence or event rules.

A data correction should include the exact source release, series/table identifier, reference period, publication date, retrieved value and any transformation used.
